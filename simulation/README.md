# Introduction

This folder contains the code for simulating Little Blue in a virtual environment. It runs using ROS2 Iron and Gazebo.

To begin, it's recommended to get the simulation up and running by following the [Environment Setup](./doc/01_environment_setup.md). Afterwards, it's recommended to follow each of the markdown docs in [doc](./doc) in order.
