# Build

Build all software:
```bash
./build
```

Build individual components:
```bash
./build sensors
```

Help:
```bash
./build -h
```

<br/>
<br/>

# Clean

Clean all software:
```bash
./clean
```

Clean individual components:
```bash
./clean sensors
```

Help:
```bash
./clean -h
```

<br/>
<br/>

# Run

Run all software:
```bash
./run
```

Run individual components:
```bash
./run sensors
```

Help:
```bash
./run -h
```
